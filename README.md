# SwipeMovie

Una app para ayudarte a decidir qué serie y película ver cuando la indecisión te ataca, o cuando no te pones de acuerdo con tus amigos sobre que ver.

## Estado del proyecto
En desarrollo.

## Funcionalidades (planeadas o implementadas)
- [x] Listado de Películas
- [x] Sistema de swipe
- [ ] Listado de Séries
- [ ] Conectividad entre usuarios

## Stack técnico
- Lenguaje: Kotlin
- UI: Jetpack Compose
- Arquitectura: MVVM + Clean Architecture
- Persistencia: Room
- Networking: Retrofit + OkHttp
- DI: Hilt
- Testing: JUnit, Mockk, Espresso
